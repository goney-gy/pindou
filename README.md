# 拼豆图纸GO

上传图片，一键生成带色号的拼豆图纸。纯静态网页，所有图片仅在本机处理，不上传任何服务器。

## 功能

- 网格尺寸：16 / 24 / 32 / 48 / 56 / 64 / 100，或自定义 8~150
- 色号系统：MARD / COCO / 漫漫 / 盼盼 / 咪小窝
- 颜色匹配：Lab 感知 / RGB 距离
- 最多用色：不限 / ≤12 / ≤16 / ≤24 / ≤32 / ≤48（限色收敛）
- 图纸选项：近白留空、格内色号、行列坐标、加重网格线、用量统计、孤立豆标记
- 三种视图：图纸 / 原图对比 / 只留空格（拖拽平移、滚轮或双指缩放）
- 导出：图纸 PNG、物料清单 CSV（带 BOM，Excel 直接打开不乱码）

## 部署到 GitHub Pages

1. 新建 GitHub 仓库，把本文件夹内文件推上去
2. 仓库 Settings → Pages → Build and deployment → Source 选 `Deploy from a branch`
3. Branch 选 `main`，目录 `/ (root)`，Save
4. 等待 1~2 分钟，访问 `https://你的用户名.github.io/仓库名/` 即可

无需任何构建步骤，整个站点就是一个 `index.html`。

## 本地预览

直接用浏览器打开 `index.html`，或用任意静态服务器（如 `npx serve`）。

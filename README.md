# 拼豆图纸GO

纯静态网页工具，所有图片仅在本机处理，不上传任何服务器。

## 功能

- 双模式：「图片生成」（照片转图纸）/「图纸识别」（识别已有图纸的每格豆色）
- 网格尺寸：16 / 24 / 32 / 48 / 56 / 64 / 100，或自定义 8~150
- 色号系统：MARD / COCO / 漫漫 / 盼盼 / 咪小窝
- 颜色匹配：Lab 感知 / RGB 距离
- 最多用色：不限 / ≤12 / ≤16 / ≤24 / ≤32 / ≤48（限色收敛）
- 图纸选项：近白留空、格内色号、行列坐标、加重网格线、用量统计、孤立豆标记
- 三种视图：图纸 / 原图对比 / 只留空格（拖拽平移、滚轮或双指缩放）
- 导出：图纸 PNG、物料清单 CSV（带 BOM，Excel 直接打开不乱码）
- 手机端保存：导出时弹层提供「保存 / 分享」（系统面板可选保存位置，如相册/文件）、长按图片存相册、下载文件三种方式
- 图纸识别两种范围：整张图纸按格子识别 / 只识别色标图例（先自动定位网格图纸区域，再在网格外侧找到图例带，提取颜色与色号并用 OCR 识别标注数量，可手动修正；图例通常在图纸下方或上方）
- OCR 三引擎链：浏览器内 PP-OCRv4（onnxruntime-web，无需服务，在线/离线可用，推荐）→ 本地 RapidOCR 服务（可选增强）→ tesseract.js 兜底
- 浅色水印过滤：只识别黑色正文，浅色水印文字自动跳过（可调亮度阈值）

## 部署到 GitHub Pages

1. 新建 GitHub 仓库，把本文件夹内文件推上去
2. 仓库 Settings → Pages → Build and deployment → Source 选 `Deploy from a branch`
3. Branch 选 `main`，目录 `/ (root)`，Save
4. 等待 1~2 分钟，访问 `https://你的用户名.github.io/仓库名/` 即可

无需任何构建步骤，整个站点就是一个 `index.html`。

## 本地预览

直接用浏览器打开 `index.html`，或用任意静态服务器（如 `npx serve`）。

## OCR 引擎与水印过滤

图例识别按以下顺序自动选择可用引擎，无需手动干预：

1. **浏览器内 PP-OCRv4**（默认，推荐）—— 模型放 `models/`（约 16MB），用 onnxruntime-web 在浏览器里直接推理，无需任何服务，部署到 GitHub Pages 后立即可用，精度接近本地 RapidOCR。onnxruntime-web 运行时已随项目打包在 `lib/ort/`（约 11MB），**本地同源加载、不依赖任何 CDN**，手机端也能正常加载；CDN 仅在本地文件缺失时自动兜底。注意需支持 WASM SIMD（iOS 16.4+、新版安卓 Chrome/Edge 均可）
2. **本地 RapidOCR 服务**（可选增强）—— 仅本机，需先启动服务，识别更快更稳
3. **tesseract.js**（兜底）—— CDN 加载，精度一般

「过滤浅色水印」默认开启：OCR 前会把亮度高于阈值的浅色像素置白，只保留黑色正文，浅色水印文字不会被识别；阈值可在设置区调整（默认 128，范围 20~230），关掉开关则识别全部文字。

本地服务启动（需 Python 3.8+，首次运行会自动下载 PP-OCR 模型约 15MB）：

```bash
pip install rapidocr-onnxruntime
python ocr_server.py        # 默认端口 8765，可用参数改端口
```

服务接口：`GET /health`（健康检查）、`POST /ocr`（body: `{"image":"<dataURL 或 base64>", "watermark":128}`，返回 JSON 文本）。仅监听本机 127.0.0.1。

# 拼豆图纸GO

图片一键转**拼豆图纸**的纯 Web 应用：网格 + 格内色号 + 行列坐标 + 每 10 格加重线，
附带色号用量统计、孤立豆结构检查、图纸 PNG 与物料清单 CSV 导出。

**手机、平板、电脑浏览器可直接使用**，点开链接即用，无需下载安装。

- **零依赖、纯静态**：无构建、无后端、无数据库，图片全部在本地浏览器处理，**不上传任何服务器**
- **5 大品牌色号系统**：MARD 221 色 / COCO / 漫漫 / 盼盼 / 咪小窝
- **Lab 感知 / RGB 两种匹配**，限色收敛（最多用色控制）
- **三种视图**：图纸 / 原图对比 / 只留空格，缩放平移查看
- **导出**：高清图纸 PNG、物料清单 CSV（Excel 直接打开，带 BOM）

## 在线使用

部署后访问 `https://<用户名>.github.io/<仓库名>/` 即可直接使用。

## 本地运行

无需构建，任意静态服务器即可：

```bash
# 方式一：Python
python -m http.server 8899
# 浏览器打开 http://127.0.0.1:8899/

# 方式二：npx
npx serve .
```

## 部署到 GitHub Pages（供分享链接使用）

1. 推送到 GitHub 仓库后，进入仓库 **Settings → Pages**
2. Source 选择 **Deploy from a branch**，分支选 `main`，目录选 **/ (root)**
3. 保存后等待 1~2 分钟，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问
4. 把该链接发给用户即可，手机 / 平板 / 电脑浏览器都直接可用

## 目录结构

```
index.html           页面骨架
css/style.css        响应式样式（移动优先，平板/桌面双栏）
js/palette.js        配色数据：5 品牌 × 221 色
js/pattern.js        量化核心：Lab/RGB 匹配、限色、用量统计、结构审计、CSV
js/viewer.js         图纸画布渲染（布局规则与导出一致）
js/app.js            应用逻辑：图片输入、生成管线、视图切换、缩放平移、导出
```

> 说明：色号已按各品牌实体色卡标准映射；如与手头实体豆有轻微色差，请以实物为准。
